# 簡化介面與排便提醒

- 主要頁面採黑、白、灰配色，首頁標題只保留「腸聽你說」。
- 新量測最多 20 秒，自動完成並前往結果頁。可提前結束或取消；既有歷史量測時間不變。舊的預設時長在載入時統一為 20 秒。
- 結果頁順序：模擬波形、模擬結果、當時狀態、其他操作。尚未串接硬體收音或真實分析。

## 提醒規則

提醒只檢查設定為「本人」的每日紀錄。連續 3 個當地日期都明確填寫「今天沒有」才觸發；漏填、僅填習慣或備註不算沒有排便。今天還沒填時，檢查截至昨天的連續 3 天；今天已記錄有排便則不提醒。

提醒在 App 首頁顯示浮動視窗，可直接查看或修正日曆紀錄。關閉後同一人當天不再提醒，狀態儲存於 `@bowelsound_reminder_seen_v1`。若寫入失敗，當次使用仍可關閉，但重新開啟 App 可能再次提醒。符合條件而未曾開啟首頁時不會發送通知。

這是 App 內提醒，不是背景推播、鎖定畫面通知或跨 App 懸浮視窗。沒有新增通知權限或背景服務。

參考 MedlinePlus 建議 3 天未排便時聯絡醫療人員，設定 3 天為產品的提醒條件，不是診斷標準，也不是建議等待就醫的時間。視窗說明持續腹痛、嘔吐、血便或無法排氣應儘速就醫。
參考：[MedlinePlus — Constipation self-care](https://medlineplus.gov/ency/patientinstructions/000120.htm)；[NIDDK — Symptoms & Causes of Constipation](https://www.niddk.nih.gov/health-information/digestive-diseases/constipation/symptoms-causes)，查閱日期 2026-10-15。

## 驗證

`npm test` 涵蓋連續 3 天、僅 2 天、日期缺口、未填寫、不同使用者、有排便後解除、跨月及過期紀錄不觸發。
手機原生背景通知與真實硬體收音不在此版本範圍內。
