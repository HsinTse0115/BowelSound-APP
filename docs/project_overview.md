# 腸音檢測系統 - 專案概覽

## 專案描述
本專案為一款「腸音檢測系統」App，用於臨床監測儀表板與腸音信號的即時採集、病患管理與視覺化分析。
- **目標用戶**：臨床醫療人員、檢測技術人員
- **運作環境**：優先於 Expo Go 上執行與測試
- **開發範圍**：專注於前端 React Native App 的開發（包含補足缺失功能頁面，後端 API 暫時採用模擬數據/ Mock Data 介面對接）。

## 技術棧
- **前端語言**：TypeScript / JavaScript (React Native)
- **前端框架**：Expo (SDK 54), Expo Router (檔案型路由)
- **樣式與 UI**：使用 Expo 內建組件與 StyleSheet 自訂樣式，搭配 Ionicons 圖示，確保視覺效果精美且符合臨床專業風格。

## 核心功能與頁面設計（提案）

### 1. 首頁儀表板 (Dashboard - `app/(tabs)/index.tsx`)
- 提供 2x2 網格功能選單：
  - 即時採集 -> 跳轉至 `/record`
  - 病患管理 -> 跳轉至 `/patients`
  - 視覺化分析 -> 跳轉至 `/analytics`
  - 系統設定 -> 跳轉至 `/settings`
- 底部顯示系統狀態提示。

### 2. 即時採集 (Real-time Acquisition - `app/record.tsx` 或 `app/(tabs)/record.tsx`)
- **功能設計**：
  - 選擇病患（從病患列表中選擇一個病患進行錄音綁定）。
  - 開始/停止採集控制，伴隨計時器與動態模擬波形圖。
  - 錄音模式：
    - **模擬錄音**（預設）：產生模擬的正弦/隨機波形動畫，計時結束後自動生成一筆腸音紀錄。
    - **真實錄製**（選配）：使用 `expo-av` 錄音，並儲存為本地音訊檔案。
  - 採集完成後提示儲存，並關聯至該病患。

### 3. 病患管理 (Patient Management - `app/patients.tsx` [新頁面])
- **功能設計**：
  - **病患列表**：以卡片形式展示所有病患，包含病患 ID、姓名、年齡、性別。
  - **搜尋與篩選**：可透過姓名或 ID 進行快速搜尋。
  - **新增病患**：提供簡易表單（ID、姓名、年齡、性別、臨床備註）新增病患。
  - **病患詳情**：點擊病患可查看其基本資訊及**歷史腸音採集紀錄列表**（日期、錄音時長、初步分析結果）。

### 4. 視覺化分析 (Visualization Analysis - `app/analytics.tsx` [新頁面])
- **功能設計**：
  - **病患與紀錄選擇**：可下拉選擇特定病患及其中一次的腸音採集紀錄。
  - **腸波與頻譜圖展示**：
    - **音訊時域波形圖 (Waveform)**：以折線圖或模擬柱狀圖展示腸音隨時間起伏。
    - **頻譜分析圖 (Spectrogram)**：以模擬熱圖或頻率能量圖展示腸音的頻率分佈。
  - **AI 分析報告摘要**：
    - 腸鳴音頻率（例如：5次/分鐘）。
    - 腸音分類狀態（正常 Normal / 亢進 Hyperactive / 減弱 Hypoactive）。
    - 臨床警示與說明。

### 5. 系統設定 (System Settings - `app/settings.tsx` [新頁面])
- **功能設計**：
  - **API 連線設定**：輸入後端 API 伺服器 URL，便於未來對接真實後端。
  - **採集設定**：設定預設錄音時長（如 10 秒、30 秒、60 秒、無限制）。
  - **硬體模擬開關**：模擬藍牙腸音感測器的連線狀態（已連線 / 未連線）。
  - **系統資訊**：顯示軟體版本、開發團隊等。

### 6. 檢測摘要 (Summary - `app/(tabs)/explore.tsx`)
- 顯示今日採集筆數、待確認訊號、模型狀態。
- 展示臨床檢測流程指引。

## 非功能需求
- **模擬數據設計**：所有新增頁面均需配備豐富且合理的 mock 數據（如預設 3-4 位模擬病患及歷史採集資料），確保在無後端連線下亦能完美展示。
- **介面一致性**：沿用現有專案的色彩計畫（藍色 `#0D6EFD`、綠色 `#10B981`、紫色 `#8B5CF6`、背景 `#F4F7FB`）與卡片圓角設計。

## 開發限制
- 完全在前端 (React Native / Expo Go) 實現，所有頁面必須在 Expo Go 模擬器上流暢運行，避免使用任何需要 Expo Prebuild 的原生套件。
