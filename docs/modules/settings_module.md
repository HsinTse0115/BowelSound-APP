# settings_module 需求規格

## 負責檔案
- `app/settings.tsx`
- `styles/settings.styles.ts`

## 功能描述
本模組實作「系統設定」頁面。提供 API 伺服器網址配置、預設錄音時長選擇、模擬藍牙腸音感測器連線狀態切換，並展示軟體系統資訊。

## 輸入 / 輸出
- **輸入**：
  - 從 `AppContext` 讀取的 `settings` 狀態。
  - 使用者編輯 API 網址、選取錄音時長限制、切換連線開關。
- **輸出**：
  - 呼叫 `updateSettings` 寫入最新設定參數至全域狀態。

## 相依模組
- `context_module` (`context/AppContext.tsx`)

## 實作要求
1. **API 連線配置**：
   - 提供文字輸入框展示目前的後端 API 位址（預設 `http://localhost:8000`）。
   - 當使用者輸入並點擊「儲存」或在編輯完成後，更新 `settings.apiUrl`。
2. **錄音時長限制設定**：
   - 提供分段控制（Segmented Control）或單選按鈕組，供選擇預設時長：`10 秒`、`30 秒`、`60 秒`、`不限`。
   - 選取後立刻同步更新至 `settings.defaultDuration`（對應數值分別為 `10`、`30`、`60`、`0`，其中 `0` 表示不限時）。
3. **感測器連線狀態模擬**：
   - 提供 Toggle Switch 切換開關。
   - 開關開啟時：顯示「模擬腸音探頭：已連線 (綠色標籤)」，同時全域的 `hardwareConnected` 設為 `true`。
   - 開關關閉時：顯示「模擬腸音探頭：未連線 (灰色標籤)」，全域 `hardwareConnected` 設為 `false`。
4. **介面外觀**：
   - 提供 Light 與 Dark 按鈕，選擇結果寫入 `settings.themeMode` 並持久保存。
   - 主導覽與主要工作頁面必須同步切換，文字與邊框維持可讀對比。
5. **系統資訊卡片**：
   - 唯讀資訊展示，包含：App 版本號（例：v1.0.0）、模型版本號（例：Edge-BowelSound-v1.2）、系統運行環境（React Native / Expo Go）。

## 測試要求

### 測試工具
- Expo Go 實機或模擬器手動操作。

### 測試情境

#### 測試情境 1：初始設定載入與呈現
- **輸入**：進入「系統設定」頁面。
- **預期輸出**：
  - 伺服器網址輸入框顯示為 `http://localhost:8000`。
  - 預設錄音時長選取在 `10 秒`。
  - 模擬感測器開關顯示為關閉（未連線）。
- **允許偏差**：無

#### 測試情境 2：更新伺服器網址
- **輸入**：將伺服器網址修改為 `https://api.bowelsound.org` 並點選儲存。
- **預期輸出**：全域 `settings.apiUrl` 變更為 `https://api.bowelsound.org`。再次進入頁面時仍能正確顯示該新網址。
- **允許偏差**：無

#### 測試情境 3：連線狀態切換
- **輸入**：開啟「模擬腸音探頭」連線開關。
- **預期輸出**：
  - 狀態標籤變為「已連線」且呈綠色。
  - 進入首頁儀表板（`app/(tabs)/index.tsx`），下方的系統提示 Banner 自底部的「邊緣運算模型與連線模組待命中」轉為「感測器已連線，信號接收就緒」。
- **允許偏差**：首頁狀態的同步需配合 AppContext 全域變數渲染。

## 禁止事項
- 禁止將設定僅儲存在本地暫時 State。任何設定的變更都必須呼叫 `updateSettings` 寫入 context。
